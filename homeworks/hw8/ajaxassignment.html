Explanation of AJAX

The JavaScript code in this page demonstrates the use of AJAX (Asynchronous JavaScript and XML) to dynamically load and display data from an XML file without requiring a full page refresh. When the user clicks the "Get CD collection" button, the loadDoc() function is triggered. This function creates a new XMLHttpRequest object, which is the core component that enables AJAX functionality. The XMLHttpRequest object is configured with an onload event handler that will execute the myFunction() callback once the XML file has been successfully loaded.

The AJAX call is initiated using the open() method, which specifies the HTTP method (GET) and the target resource (cd_catalog.xml). The send() method then dispatches the request to the server. This entire process happens asynchronously, meaning the browser can continue to respond to user interactions while waiting for the XML data. Once the XML file is received, the myFunction() function parses the XML document using responseXML, extracts all CD elements, and iterates through them to build an HTML table dynamically. The table is then inserted into the page using innerHTML, updating only the specific section of the page without reloading the entire document.

REST API

The Riot Games API is a REST API that provides data about League of Legends, Valorant, Teamfight Tactics, and other Riot games. It's a free API that allows you to access data about the games, including players, matches, and other game-related information. When making a call to any Riot API, you need to provide an API key, which is provided by Riot Games after applying for a developer account. The Riot Games API returns data in JSON (JavaScript Object Notation) format, which is lightweight, easy to parse, and widely supported across all modern programming languages and frameworks.

For any company looking to use the Riot Games API, using the API is free, and you can monetize your product as long as it doesn't feature gambling functionality. Developers must be careful not to violate the game integrity terms of service such as allowing players an unfair advantage.
